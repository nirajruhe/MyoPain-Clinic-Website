# MyoPain Physiotherapy & Wellness Clinic

Official website for **MyoPain Physiotherapy & Wellness Clinic**, led by **Dr. Neeraj Ruhela (PT)** (MPT - Musculoskeletal & Sports, Ex-NIMHANS, JMMT Certified) and **Dr. Shrishti Pant (PT)** (MPT - Neurology).

Providing evidence-based comprehensive physical rehabilitation in Ghaziabad, Uttar Pradesh.

---

## 🌟 Clinic Highlights
- **Evidence-Based Comprehensive Rehabilitation:** Multidisciplinary treatment covering Musculoskeletal, Neurological, Sports Injury, Geriatric, Pediatric, Workplace Ergonomics, Post-Operative, and Chronic Pain management.
- **Advanced Therapy Modalities:** Japanese Manual Therapy (JMMT), Dry Needling, Kinesio Taping, Balance & Gait Retraining, Matrix Rhythm Therapy, and Custom Exercise Prescription.
- **Home Visit Physiotherapy:** Dedicated home rehabilitation sessions for post-stroke, elderly, and post-surgery patients.
- **Verified Google Reviews:** 5.0-star patient reviews covering real recovery journeys for facial paralysis, stroke mobility, knee ligament rehabilitation, cervical spine care, and sports injuries.

---

## 💻 Tech Stack & Architecture
- **Structure:** Semantic HTML5 with accessible landmarks, SEO tags, and Open Graph metadata.
- **Styling:** Modern, modular Vanilla CSS3 design system with custom CSS custom properties (tokens), fluid typography (`clamp()`), and responsive layouts.
- **Interactions:** Vanilla JavaScript (`script.js`) powering:
  - 12-Service single-row horizontal carousel with touch swipe and button controls.
  - Interactive FAQ accordion.
  - Quick WhatsApp appointment draft generator.
  - Mobile responsive hamburger navigation.
- **Accessibility:** WCAG 2.2 AA compliant contrast, keyboard navigation, and `:focus-visible` states.
- **Performance:** Optimized WebP and JPG imagery with zero heavy framework overhead.
